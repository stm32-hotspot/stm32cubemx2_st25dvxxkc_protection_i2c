# Release Notes for <mark>stm32cubemx2_st25dv64kc_protection_i2c</mark>

# Purpose

This example demonstrates how to use the ST25DV64KC part driver with STM32CubeMX2 for user-zone protection and secure read/write access control over I2C.

Initial release of the ST25DV64KC protection_i2c example for STM32CubeMX2.

Configuration and code generation features require STM32CubeMX2 >= 1.0.0.
